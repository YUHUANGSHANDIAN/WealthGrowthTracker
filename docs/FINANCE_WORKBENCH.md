# 统一理财工作台

## 入口与任务

一级入口为「理财」，包含七个四字任务：

- 初始对账
- 月度复盘
- 临时调仓
- 基金分析
- 止盈审查
- 市场情报
- 专项研究

正式月度任务使用 `monthly-planning:YYYY-MM`，每账本每月一条；其它任务使用 `finance-task:<id>`。临时任务可关联正式月记录，但关联不会覆盖月记录。

## 持久化

`monthly_planning_state` 当前 schema 为 2。读取 schema 1 时，旧月记录迁移为 `monthly-review`，原键和内容保持不变。

材料化修订在 `planned`、`confirmed`、`reviewed`、`archived`、`cancelled` 状态保存完整快照。归档任务重开必须递增 revision，旧归档快照不被改写。

## 状态

共享阶段为：`draft → extracting → reviewing → ready → planned → confirmed → reviewed → archived`，并有 `blocked` 与 `cancelled`。

- 初始对账：确认真实基线后进入复核与归档。
- 月度复盘、临时调仓、止盈审查：必须绑定策略和候选方案。
- 基金分析、市场情报、专项研究：不生成伪交易，复核前必须有结构化结果。
- “无需交易/无需操作”是合法结果。

## 核算边界

- 只有一个权威资产账本；任务观察值不会直接覆盖渠道资产。
- 金额使用元 + number；份额、净值和费率使用十进制字符串；内部比例使用 0–1。
- 未知、缺失、不适用和真实 0 分开表达。
- 来源日期、估值日期、观察日期、导入日期和报告日期分开保存。
- 应用不调用交易、转账或还款接口；执行回执只记录用户在外部平台实际完成或撤销的动作。

## 离线能力

资料导入、结构化候选、对账、确定性计算、人工方案、结果复核、归档、搜索与备份均不依赖 AI。市场情报的联网来源核验仅在桌面端且用户显式提供 HTTPS 链接时启用。
