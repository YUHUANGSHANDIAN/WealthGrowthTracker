# AI 真实账号验收（视觉提取与网页检索）

本文档是**可复制执行**的验收清单，用来把「视觉提取」和「网页检索」从「代码完成、mock 通过」
推进到「真实账号验收」。它不改代码、不写入任何事实：视觉输出只读展示，检索结果必须由你
显式点「保存为研究记录」才会落进会话。

> 两条硬规矩
> 1. **API Key 不要粘贴到对话、Issue、提交或任何文档里**；只在应用界面里输入，桌面版会交给系统安全存储。
> 2. API Key 是按量计费连接，**不计入「双订阅发布门」**；本清单通过也不改变预览版的发布性质。

## 前置

- 桌面版（Windows/macOS/Linux）已安装并启动；AI 默认关闭是预期行为。
- 准备一个可读图的 API Key（或你自己的兼容网关）。Web/移动端只能走自建 HTTPS 网关或本机端点。
- 准备一张**合成**截图（≤ 1 MB，PNG/JPEG/WebP）。单张超过约 1 MB 会被拒绝并提示压缩，
  这是协议层的体积上限，不是模型能力问题。**不要用真实对账单做验收**。
- 准备 1 个公网 HTTPS 链接（例如某个官方文档页），不要用内网地址。

## 必须成立的失败关闭行为

| 场景 | 期望结果 |
|---|---|
| 用一个**没有勾选**「可接收图片」的连接点「视觉识别」 | 提示「此连接未被声明为可读图，无法发送图片…」（`VISION_UNSUPPORTED`），且**确实没有发出图片** |
| 未启用 AI 时点「视觉识别」或「联网检索」 | 提示「请先在 AI 连接中心启用 AI 并选中一个连接」 |
| 在 Web/PWA 上点「联网检索」 | 提示「当前平台不提供联网检索…」（`RESEARCH_UNAVAILABLE`），不会偷偷改用搜索引擎 |
| 粘贴 `http://` 地址、带凭据的地址或内网地址 | 提示「只能检索公开的 HTTPS 链接…」（`INVALID_URL`） |
| 上传非 PNG/JPEG/WebP 的图片（如 BMP） | 提示「仅支持 PNG / JPEG / WebP 截图；请先转换格式再识别」 |
| 视觉模型拒绝或超时 | 提示可读错误并让你重试；**不产生任何半成品数据** |
