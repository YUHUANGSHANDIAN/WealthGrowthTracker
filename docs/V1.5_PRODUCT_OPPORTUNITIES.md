# V1.5 产品机会审查（Product Opportunities）

> 从 产品经理 / 数据工程师 / 本地优先软件架构师 三个视角系统审查 v1.4，评估后续候选功能。
> 评级：Impact（用户价值）、Effort（实现成本）、Risk（数据/隐私/复杂度风险）。

## 已在 v1.4 实现（不进入 v1.5）

- 报告冲突安全生成、可编辑元数据、历史修复
- 交互式 Data Health Center
- 彩票资金池（隔离账本 + Excel 迁移）
- 跨 Feature 深链（Data→Reports/History/Goals/Lottery、Report→Analysis、Goal→Prediction、Health→数据定位）
- 活动日志（本地、不记录敏感数据）

## 候选功能评估

| 功能 | Impact | Effort | Risk | 推荐 |
|---|---|---|---|---|
| **Global Search**（渠道/报告/目标/彩票项目） | 高 | 中 | 低 | ✅ v1.5 首推 |

| **Report Tags**（年度总结/旅行/重要节点，已有基础字段） | 中 | 低 | 低 | ✅ v1.5 |
| **Data Reconciliation**（今日总资产 vs 最新历史快照一致性） | 高 | 中 | 低 | ✅ v1.5 |
| **Dashboard Widgets**（用户决定首页显示） | 中 | 中 | 低 | 考虑 v1.5 |
| Activity Log 高级筛选 / 导出 | 中 | 低 | 低 | ✅ v1.5 |

| 深色模式（完整 Dark Mode） | 中 | 高 | 中 | 延后（需图表/弹窗/分享图全适配） |

| 云同步 / 账号 / 行情 API / 大模型 | — | — | 高 | ❌ 明确不做 |

## 推荐 v1.5 优先级（Top 4）

1. **Global Search**：跨渠道/报告/目标/彩票项目统一搜索（本地索引，无服务器）。实现：本地倒排索引 + Ctrl/Cmd+K 快速框。
2. **History Notes**：为某天资产变化添加备注（如「年终奖入账」），进入报告上下文与趋势 Tooltip。
3. **Data Reconciliation**：检查今日总资产与最新 History Snapshot 是否一致，不一致时给出差异与修复建议。
4. **Report Tags 增强**：v1.4 已有 `tags` 字段，v1.5 增加标签筛选、标签页与报告按标签分组。

## 隐私约束（所有候选功能必须遵守）

- Local-First：不引入服务器/账号/云数据库。
- 不接入 analytics / telemetry / 广告 / 第三方资产 API。
- 业务数据（渠道/历史/彩票）只存本地 storage，Service Worker 不缓存用户 JSON。
- 敏感数据（密码/PIN hash）不进入任何日志/备份。
